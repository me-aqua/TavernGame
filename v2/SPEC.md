# TavernGame v2 · SPEC（阶段 2 基线）

> 版本：2026-11-27 · 阶段 2.2 基线（初始值归根 + 公历三模式 + 三类节日）
> 位置：仓库内 `v2/`，独立 Vite 应用；**不 import 旧站 `src/` 任何代码**。
> 部署：GitHub Pages `https://me-aqua.github.io/TavernGame/v2/`；旧站根路径保持只读可用。
> 技术：Vue 3 + TypeScript + Vite + Vercel AI SDK；**从 0 写新组件，不 import 旧站 `src/`**；浏览器直连 provider，Key 只存本地。

## 1. 页面与路由

| `#/`                     | 首页         | 左：游戏卡列表；右：存档列表；新建/重命名/删除   |

## 2. 数据模型（`schemaVersion: 1`）

### Card

```js
{
  schemaVersion: 1,
  id, name,
  state: [ { code, name, note, type, values?, min?, max?, stepMin?, stepMax?,
             timeMode?, holidays?, initial? } ],
  chain: [ { id, type, name, reads, writable, readsUpstream, historyTurns, prompt } ], // 不含 presetId
  prompts: [ { id, title, body } ]
}
```

- **状态树（2.1）**：`type ∈ 'time' | 'text' | 'integer' | 'enum' | 'object'`，**作者只能选 `text` / `integer` / `enum` / `time`**（`object` 是「有孩子」的内部形态，下拉里没有）；一个节点**可以同时有自己的值和孩子** —— 自身值住在隐式的 `<code>.0`（不进 `state[]`），可见孩子从 `<code>.1` 起连续编号；`object` 没有自身值、必须有孩子；深度（`.0` 不计）最大 5；`state[0]` 必须是时间元素 `0`（整张卡只有一个时间）。
- **初始值归根（2.2）**：`initial` 只挂在**根元素**（`code` 不含 `.`）上，而且它是**整棵子树的扁平值表**（键 = 完整 code，和 `tree` 同一套口径）；时间根例外 —— 它的 `initial` 就是时间值本身。子元素存 `initial` 即坏卡。新建存档的树由 `initialTreeOf(card)` 摊平。
- **时间（2.2）**：时间元素带 `timeMode`（`year-minute` 年月日时分 / `year-date` 年月日 / `days-minute` 天数时分）与 `holidays`（前者两个模式三个布尔，`days-minute` 不许有）。年份 `-551 … 9999`、**没有 0 年**，显示「公元前 N 年」；公历按天文年算（公元前 1 年是闰年）；**没有秒**；能推进哪些单位**只由模式决定**（年-分钟六种 / 年-日期四种 / 天数-分钟三种），卡里没有颗粒度字段。
- **节日（2.2）是派生只读**：三组勾选（现代国际 7 条公历固定日 / 现代中国 3 条公历固定日 / 中国传统 11 条），由「时间值 + 勾选」当场算，不写进 `state[]` / `tree` / 事件；中国传统只支持 1900–2100（有界农历表，勾选永远可点，表外年份静默不产出）；提示词只在读了时间元素时多一行 `节日：…`。
- `chain[].type`: `'time' | 'normal' | 'output'`（**没有校对节点**）。
- 链约束：**恰好 1 个 output、最多 1 个 time**；首节点不能读上游。
- 读写语义：`prompts[].id ∈ reads` 表示节点读这一块公共提示词；`state[].code ∈ reads` 表示读该元素（**一个 code 覆盖自身值 + 整棵子树**），`<code>.0 ∈ reads` 表示**只读这个元素的自身值**（只有「有孩子的非结构体」有这一格：叶子用 `<code>`、`object` 没有自身值）；`readsUpstream: string[]` 表示读哪些**前序节点**的输出（只能指当前节点之前的节点）；`writable` 表示可写该元素（同样可以写 `<code>.0`），**它是唯一的写权限来源**（节点类型不限制能写哪个元素，`output` 除外 —— 它什么也不写）。

### Save

<!-- prettier-ignore -->
```js
{
  schemaVersion: 1,
  id, cardId, cardSnapshot, // 整张卡冻结
  nodeModels, // 可选：这一份存档自己的节点映射（新建时从卡映射拷一份；缺省 = 旧存档，播放回落卡级）
  name, turn, tree, events, updatedAt
}
```

- `tree`: **扁平完整 code 的值表** —— 每个根元素的初始值摊平，`object` 的自身 code 不是键、有孩子的节点自身值在 `<code>.0`；时间值按模式给格子（`{year,month,day,hour,minute}` / `{year,month,day}` / `{day,hour,minute}`）。
- `nodeModels`: `{ [nodeId]: presetId }`。播放优先用它，没有才用卡级 `tg2.nodeModels[cardId]`（旧存档不迁移）；
  存档编辑器改的是它，卡的映射不动。
- `events`: `[{ type: 'action'|'narration'|'node'|'request'|'tool'|'write'|'toolResult'|'error'|'trace'|'turnStats', text, detail?, at }]`。
- 新建存档时 `tree` 由卡的初始值展开（`initialTreeOf`）；之后改卡不影响旧存档。

### Preset

```js
{ id, name, provider: 'openai-compatible'|'mock', baseUrl, model, apiKey, reasoning }
```

## 3. 存储

- localStorage keys：`tg2.cards` / `tg2.saves` / `tg2.presets` / `tg2.settings` / `tg2.nodeModels`；**不读写旧站 `tg.*`**。
- 项目本体**不含玩家卡 / 存档**；随包只带一张**示例卡资产**（`src/data/sample-card.json`），由首次启动种入 localStorage：**种入时换成运行时不透明 id `c-<uuid>`**（与首页新建卡同一套生成器），资产名永远不出现在 URL / 存档里；玩家可删除；删后卡列表为空、新建卡、编辑器、引擎、设置照常工作（存档不受删卡影响，见 §5）。
- 首次打开：自动种入晨风镇示例卡 + 两条默认预设（只种一次，`sampleSeeded` 标记）；玩家删光后不再自动长回来。
- 示例卡形状：时间（`0`，`year-minute` 模式 + 三组节日都不勾）+ `1 世界` / `2 玩家`（都是 `text` + 空自身值 + 子节点，`object` 只是后台形态）+ 各自的子元素；初始值住在两个根元素身上（`1.0` / `2.0` 是它们自己的空串，孩子各一格）。

## 4. 引擎

```js
runTurn({ card, save, presets, nodePresets, action, onEvent }) → { save, events }
```

- 顺序执行链；**工具由 `writable` 覆盖到的值派生**（节点类型不限制写什么，`output` 除外）：覆盖到时间元素 `'0'` ⇒ `advance_time({ amount, unit })`（正整数 + 模式单位表内，公历推进、月末夹取；**声明给模型的 `unit` 枚举按当前时间模式收窄**，模型看不到模式外的单位）；覆盖到普通元素 ⇒ `write_state({ path, value })` 只能写覆盖到的值路径（完整 code；有孩子的节点自身值是 `<code>.0`），值按类型收（文字 / 整数含上下限与单次步幅 / 下拉白名单）；两样都覆盖 ⇒ 两个工具。只有 `output` 节点产故事。
- 提示词拼装顺序：公共提示词（按 reads，每块带 `<公共提示词·标题>`）→ 状态树（按 reads，带 `<世界状态树>`；每个读到的元素一行 `- <code>「<name>」：<JSON>`，有孩子的节点输出自身值 + 整棵子树，**JSON 键是中文名：自身值 `"自身"`、子字段用元素 `name`，没有 `"0"` / `"1"` 这种 code 键**，时间按模式输出一行，节日非空时紧跟一行 `节日：…`）→ **历史（带 `<游戏历史记录>`；卡里的「开场」正文是第 0 条输出，`读取历史回合=0` 只带当前 action，`=1` 带最近 1 条输出 + 当前 action，`=n` 带最近 n 条输出 + 含当前在内的最近 n 次 action）** → 上游输出（`readsUpstream` 里点名的前序节点，每段带 `<上游输出·节点名>`，按链顺序拼接）→ 本节点提示词（带 `<节点提示词>`）。空段连标记一起省略。
- 流式：output 节点流式回调 `onEvent({type:'chunk', text})`；可中止。
- 错误：`E_PROVIDER`（网络/key/额度）· `E_VALIDATION`（卡/存档不合法）· `E_CHAIN`（链不合法）· `E_UNKNOWN` · `E_ABORTED`（用户点停止）；中文提示 + 下一步。

## 5. 页面细节

### 首页

- 两栏并排；游戏卡列表右上「＋ 新建游戏卡」，存档列表右上「＋ 新建存档（基于选中的游戏卡）」。
- 卡行：名字、存档数、重命名、删除（确认）。
- 存档行：名字、`游戏卡名 · 第 N 回合`、编辑游戏卡（进存档编辑器）、重命名、删除（确认）。
- **删卡只删卡本身**：它的存档全部保留（每份存档带整张卡的快照，能继续打开玩），模型映射也保留；
  **删存档只删那一份**，不动卡。确认文案说清「存档会保留」。

### 编辑器（阶段 2.1 / 2.2）

- 四区：左状态树（宽度可拖）· 工作流细条（**固定宽度**）· 中编辑（可拖）· 右公共提示词（可拖）。
- 状态树：按 code 缩进；每行只有编码 + 名称 + **文字按钮【读】【写】**（**不显示初始值 / 当前值**），父行三态（满 / 半 / 未）= 自身值 + 整棵子树，子节点只切自己；可加子元素（第 5 层不给）、可删（时间不可删，删除要确认）；给标量加孩子**不转换类型**，自身值在所属根的初始值表里搬到 `.0`。
- 中栏：类型（文字 / 数字 / 下拉 / 时间；**结构体不在下拉里**，导入的 `object` 照实显示）、名字、备注、类型自己的格子（enum 取白名单、integer 上下限与步幅、time 的三个节日勾选）；**时间元素的类型行就是模式选择器**（年-分钟 / 年-日期 / 天数-分钟，底层 `type` 仍是 `time`；不再有单独的时间模式行）。**中栏分两段**：上半放结构字段、下半从 ~50% 起放初始值块（不贴底、两块间至少 16px、放不下就滚动）。
- **初始值块跟着「根」走**：只有选中的是根元素才出现 —— 每条值路径一行，从左到右是**编号 → 中文名 → 值控件**；编号按左栏同一把尺缩进（每层 12px），容器本体显示 `1.1` 而不是 `1.1.0`（存储仍是 `.0`）；integer 行在输入框右边用小字标 `min~max`。选中的是子元素就整块没有。时间元素按模式给 5 / 3 / 3 格，每格右边紧邻单位（年 / 月 / 日 / 时 / 分）。
- **换时间模式**：卡模式可换，先确认；取消 ⇒ 一个字不动；确定 ⇒ 时间初始值重置成新模式默认、天数模式删掉节日勾选（切回年份模式补一份全关的）。存档模式类型行锁死（看得见改不了）。
- **节日勾选**：只在前两个模式出现，三个都永远可点、同一水平行、左对齐（中栏放不下时横向滚动，不换行）；勾选框是页面自定义的 14×14 小方盒（不是浏览器原生蓝框，点按热区 24×24）；传统节日旁常驻「仅支持 1900–2100」。
- **保存按钮**：编辑只改内存草稿，顶栏【保存】才校验 + 落盘；校验不过不写盘、草稿保留、中文错误清单可点回；成功提示 **3 秒后自动消失**；有未保存改动点【返回】先确认（取消留在编辑器）；删公共提示词也要确认。
- 工作流：固定三节点（时间 / 判定 / 输出）；选中节点后，**前序节点**旁出现「读」按钮（读它的输出），自己与下游没有；中栏编辑节点名字、提示词、**模型预设（本地映射，不写卡）**、历史轮数。
- 右栏：公共提示词块，块前有眼睛（节点是否读它），可增/删/改。
- 栏宽拖拽：左/中/右可拖，双击恢复默认，存本地；细条固定。

### 存档编辑器

- 入口：首页存档行「编辑游戏卡」→ `#/edit-save/:saveId`；返回回首页。格式与编辑器相同（四区、栏宽、状态机、保存按钮）。
- **改的是这一份存档的 `cardSnapshot`（深拷贝），不是卡带库**：卡库一个字节不动；刷新 / 重开还在。
- **结构锁死**：没有加 / 删状态元素（按钮不出现）、没有节点增删排序、卡名不可改；**初始值整块不渲染**（当前值住在 `save.tree`，数字元素在上下限下方显示 `[data-current-value]`）。
- 可改：状态名字 / 备注、公共提示词标题 / 正文 / 增删（「开场」不可删）、
  节点名字 / 节点提示词 / 历史轮数 / 读 / 写 / 读上游、节点模型预设。
- 保存：校验**新的卡快照容得下这一份存档的当前树**（路径都在、值合类型与上下限；**不判初始值**）；不兼容 ⇒ 不写盘、草稿保留、错误点名路径。
- 模型：改的是 `save.nodeModels`（卡级 `tg2.nodeModels[cardId]` 不动）；新建存档时从卡级映射拷一份。

### 对话页

- 直接显示 `opening` 提示词块的正文 → 故事流 → 输入框 + 「发送」。**没有封面 / 开始按钮。**
- 发送后：禁用输入、流式显示故事、可「停止」；完成自动存档并更新回合。
- 页面只有故事流 + 输入框 + 发送；**不做显示面板**。
- 右上角调试开关：开 ⇒ 每节点的输入 / 输出 / token / t/s / 耗时 + 本轮总计；关 ⇒ 只看输出节点的最终故事 + 本轮总耗时。`?debug=1` 只是初始开。

### 设置

- 主题：浅色 / 深色；持久化。
- 模型预设：名称 / Base URL / 模型 / Key / 思考强度；增删改；默认两条 DeepSeek（V4 Pro / Flash）；Key 不写日志。

## 6. UI 与响应式

- 淡褐色 token；浅/深两套；`color-scheme` 跟随。
- 桌面/大屏最小 **1280×720**，最大 4K 16:9；兼容 16:9 / 16:10 / 4:3 / 21:9。
- 手机浏览器：竖屏显示「请横屏使用」遮罩；点击后尝试 `screen.orientation.lock('landscape')`，失败提示手动旋转；横屏进入布局。
- 不添加低于 720p 的分辨率档。
- 组件故事：`v2/stories/` 每个组件至少一个故事页；固定 1280×720；浅/深两主题；结构检查（横向溢出、出界、24px 点按、遮挡）+ 三档字号；不建组件像素基线；生成总览页。
- 整页巡检：四类比例代表档 + 4K；稳定画面像素基线（`maxDiffPixelRatio: 0.01`，动画禁用，caret 隐藏）；只跑 chromium。

## 7. 构建与部署

- `v2/vite.config.mjs`：`base: '/TavernGame/v2/'`，`build.outDir: '../dist/v2'`。
- 根 `package.json` scripts：
  - `v2:dev` → `vite --config v2/vite.config.mjs`
  - `v2:build` → `vite build --config v2/vite.config.mjs`
  - `v2:test` → vitest（v2 测试）
  - `v2:e2e` / `v2:stories` → playwright
- 部署 workflow：先 `npm run build`（旧站），再 `npm run v2:build`（产物进 `dist/v2`），上传 `dist`。旧站根路径保持。
- 每阶段完成即可推 `main`，`/v2/` 真浏览器验收。

## 8. 阶段 2.2 不做

**农历时间模式**、**古代节日**、**全范围农历库 / 第三方历法库**、清明（节气不是农历节日）；导入导出、复制副本、节点增删排序、**数组 / 字典 / 键字段 / 运行期容器增删 / 整表替换**、显示面板、重生成/撤销、连接测试、token 费用、多语言、自定义主题色。

## 9. 验收口径

1. 首页空态：项目无卡时显示「还没有游戏卡」，能新建。
2. 新建卡 → 改 2 个文本元素 + 初值 + 2 块提示词 → 新建存档 → 发送行动，流式连跑 3 回合 → 刷新，卡/存档/回合/故事都在。
3. 读开关：关掉某提示词块 / 某状态元素 / 某前序节点输出 → 调试面板对应 prompt 里内容消失。
4. 改卡后旧存档仍能跑（快照）；**但不做旧格式兼容**：旧卡（带 proof / 布尔 readsUpstream / 缺 opening / `type:'string'` / `{day,hour}` 时间）打开必须是中文 `E_VALIDATION`，非法项的 JSON 值不变（deep-equal；不承诺字节/格式），首页不许出现可点击的“新建游戏卡”去覆盖它。
5. 四类比例（1280×720 / 1280×960 / 1280×800 / 2560×1080）+ 4K 无横向溢出/出界；手机竖屏出现横屏遮罩。
6. 编辑器三栏可拖宽、细条固定、双击恢复、刷新保留。
7. 状态树：文字 / 数字 / 下拉 / 时间都能建（`object` 只是后台形态，类型下拉里没有）；节点可同时有自身值和子节点（`1.1` 是区域、`1.1.1` 是地点），`.0` 不单独显示、左栏也不显示初始值 / 当前值；父【读】/【写】= 自身值 + 子节点全选/全反选；数字上下限/步幅与下拉白名单生效；时间推进单位由模式决定（没有颗粒度字段）；保存按钮校验不过不写盘、草稿保留，修好能保存；深度 > 5、空对象、坏 code 被拦。
8. 初始值归根：只有根元素有初始值（子元素的页里没有初始值块）；加 / 删 / 换类型之后所属根的初始值跟着改，保存后落盘的形状对得上；存档模式不显示初始值。
9. 时间：三个模式各自的格子与可推进单位、年份范围（公元前 551 到 9999、没有 0 年）、公元前显示、月末夹取、天数模式进位；换模式要确认，取消不动、确定重置；存档模式模式锁死。
