TavernGame

一个用 agent 循环驱动的文字游戏。
既能做卡，也能玩卡。

开发中 · v0.3.0
⚠️ 这个网站不能直接玩。
TavernGame 是一个「软件型」项目 —— 需要在你自己的电脑上运行， 由你提供自己的 API key。这里只是一张介绍页。

它是什么

传统 AI 角色扮演工具（比如酒馆）是轮次对话：你说一句，它回一句。

TavernGame 换成 agent 循环：你给一条指令，它自己思考、调用工具、 掷骰判定、修改世界状态，把整个回合跑完再给你结果。

游戏状态由引擎持有，不是由模型随口说的 —— 所以数值不会崩、 剧情不会自相矛盾。

怎么跑起来

方式一：一键启动（推荐）
下载下面的启动脚本，放进项目文件夹的 public 目录，双击即可。 它会自动检测环境、启动服务器、打开浏览器。

⬇ 下载 start.bat

方式二：手动命令

# 1. 克隆仓库
git clone https://github.com/me-aqua/TavernGame.git
cd TavernGame

# 2. 启动服务器（零依赖，不需要 npm install）
npm start

# 3. 浏览器打开
http://localhost:3000/play.html

⚠️ 前置条件：需要 Node.js 18 或更高版本 （nodejs.org）。
