# TavernGame

> 一个用 **agent 循环**驱动的文字游戏 —— 既能做卡，也能玩卡。

## 直接开玩

**不需要安装任何东西。** 打开网址 → 填一次自己的 API key → 开始玩。

### 👉 https://me-aqua.github.io/TavernGame/

API key 保存在**你自己的浏览器**里，请求直接从浏览器发往服务商，
不经过任何中间服务器。

## 这是什么

传统 AI 角色扮演工具（比如酒馆）是**轮次对话**：

> 你说一句 → 模型回一句 → 你说下一句

TavernGame 用**回合制 agent 循环**：

> 你给一条指令 → agent 自己思考、调用工具、掷骰判定、
> 修改世界状态 → 把整个回合跑完 → 给你结果

关键在于**「谁持有事实」**：

| 角色 | 负责什么 |
| --- | --- |
| **LLM** | 理解意图、生成叙事、做判断 |
| **引擎**（代码） | 掷骰、算数值、改状态、存盘 |

模型**碰不到真实数据**。它说「你的血量变成 999」没有用 —— 引擎不认。
它必须调用 `adjust_stat`，而那个函数会把数值限制在合法范围内。

### 这意味着什么

- **掷骰由引擎执行**：模型无法预测或编造点数
- **状态不会崩**：数值改动必须走工具，走工具就被 clamp
- **可调试**：模型想干什么，你在界面上直接看得到

## 支持的服务商

已实测支持浏览器直连（CORS 允许）：

| 服务商 | 说明 |
| --- | --- |
| **DeepSeek 官方** | 默认选项，最省事 |
| 硅基流动 | 国内可用，模型多 |
| OpenRouter | 模型最全 |
| Mistral | — |
| **本地 Ollama** | **零成本**，跑在你自己电脑上 |

> Groq 实测不允许浏览器直连，用不了。

## 工具系统

模型可以通过这些工具改变世界：

| 工具 | 作用 |
| --- | --- |
| `set_stat` / `adjust_stat` | 修改属性或 HP |
| `roll_check` | 属性检定（引擎掷 1d20） |
| `add_item` / `remove_item` | 背包增减 |
| `set_scene` | 切换场景 |
| `set_npc` | 记录人物 |
| `set_flag` | 记录剧情标记 |

## 存档

- **自动保存**：存在浏览器 localStorage，刷新不丢
- **导出 / 导入**：界面右上角有按钮，可下载成 JSON 文件

> ⚠️ localStorage 会随浏览器缓存一起被清理。
> 重要存档记得**导出成文件**。

## 本地运行（可选）

想离线玩或改代码：

```bash
git clone https://github.com/me-aqua/TavernGame.git
cd TavernGame
npm start                       # 需要 Node.js 18+
# 打开 http://localhost:3000/
```

Windows 用户也可以直接双击 `start.bat`。

## 项目结构

```
TavernGame/
├── index.html       项目介绍页
├── about.html        游戏界面（本体）
├── core/            核心逻辑

│   ├── llm.js       LLM 调用

```

## 设计原则

- **纯前端** —— 没有服务器，没有构建步骤，没有依赖
- **零 npm 依赖** —— 全部用浏览器原生能力
- **模型与事实分离** —— 见上文
- **不追求和酒馆兼容** —— 玩法不同，没必要迁就旧格式
