# TavernGame

> 一个用 **agent 循环**驱动的文字游戏 —— 既能做卡，也能玩卡。

## 直接开玩

**不需要安装任何东西。** 打开网址 → 填一次自己的 API key → 开始玩。

### 👉 https://me-aqua.github.io/TavernGame/

API key 保存在**你自己的浏览器**里，请求直接从浏览器发往服务商，
不经过任何中间服务器。

## 这是什么

传统 AI 角色扮演工具（比如酒馆）是**轮次对话**：

> 你说一句 → 模型回一句 → 你说下一句

TavernGame 用**回合制 agent 循环**：

> 你给一条指令 → agent 自己思考、决定要不要推进时间、
> 把整个回合跑完 → 给你一段完整的故事

### 设计取向：极简

早期版本让模型维护八种工具（属性、背包、NPC、剧情标记、掷骰……），
它每回合要输出大量 JSON 去记账 —— **注意力被从「写故事」上挤走了**。

现在**只剩一个工具**：时间。

| 谁 | 负责什么 |
| --- | --- |
| **LLM** | 写故事、判断成败、决定时间是否推进 |
| **引擎**（代码） | 持有并保护唯一的结构化状态：时间 |

## 时间引擎（唯一的工具）

一天分三段：**上午 → 下午 → 晚上**，循环往复。

- 模型判断这一回合该不该推进时间（赶路、长谈、睡了一觉……）
- **引擎负责把关**：拒绝倒退、拒绝原地不动、拒绝一次推超过 6 段
- 界面上会显示「第几天 · 什么时段」

时间之所以被保留，是因为它是**最底层的引擎** ——
驱动节奏、事件、NPC 作息，而且只有一个状态，不需要「账本」。

> 大多数回合**根本不需要调用任何工具**。几句话、几个动作，
> 直接写故事就好。

## 支持的服务商

已实测支持浏览器直连（CORS 允许）：

| 服务商 | 说明 |
| --- | --- |
| **DeepSeek 官方** | 默认选项，最省事 |
| 硅基流动 | 国内可用，模型多 |
| OpenRouter | 模型最全 |
| Mistral | — |
| **本地 Ollama** | **零成本**，跑在你自己电脑上 |

> Groq 实测不允许浏览器直连，用不了。

## 存档

- **自动保存**：存在浏览器 localStorage，刷新不丢
- **导出 / 导入**：界面右上角有按钮，可下载成 JSON 文件

> ⚠️ localStorage 会随浏览器缓存一起被清理。
> 重要存档记得**导出成文件**。

## 本地运行（可选）

想离线玩或改代码：

```bash
git clone https://github.com/me-aqua/TavernGame.git
cd TavernGame

npm run dev        # 需要 Node.js 18+，零依赖，不用 npm install
# 打开 http://localhost:3000/
```

Windows 用户也可以直接双击 `start.bat`。

> 本地调试服务器**禁用了缓存**，改完代码刷新即生效 ——
> 不会出现「代码改了但浏览器还在跑旧 JS」那种假象。
>
> ⚠️ localStorage 按域名隔离：`localhost` 与线上各存一份 API key，
> 首次在本地调试要重新填一次。

## 项目结构

```
TavernGame/
├── index.html       游戏界面 —— 本体
├── about.html       项目介绍页
├── core/            核心逻辑
│   ├── agent.js     agent 循环 ← 灵魂
│   ├── tools.js     工具定义与执行（只有时间引擎）
│   ├── state.js     世界状态与存档
│   ├── llm.js       LLM 调用
│   ├── config.js    配置与服务商预设
│   └── prompts.js   提示词 ← 改玩法主要改这里
├── dev-server.js    本地调试服务器（禁用缓存）
├── start.bat        Windows 一键启动
└── assets/          静态素材
```

## 设计原则

- **纯前端** —— 没有服务器、没有构建步骤、没有 npm 依赖
- **零依赖** —— 全部用浏览器原生能力；本地调试服务器也只用 Node 内置模块
- **极简优先** —— 每加一个工具，就多一分从叙事上分走的注意力
- **不追求和酒馆兼容** —— 玩法不同，没必要迁就旧格式
