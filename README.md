# TavernGame

> 一个用 **agent 循环**驱动的文字游戏 —— 既能做卡，也能玩卡。

## 这是什么

传统 AI 角色扮演工具（比如酒馆）是**轮次对话**：

> 你说一句 → 模型回一句 → 你说下一句

TavernGame 换一种方式，用**回合制 agent 循环**：

> 你给一条指令 → agent 自己思考、调用工具、掷骰判定、
> 修改世界状态 → 把整个回合跑完 → 给你结果

关键在于**「谁持有事实」**：

| 角色 | 负责什么 |
| --- | --- |
| **LLM** | 理解意图、生成叙事、做判断 |
| **引擎**（代码） | 掷骰、算数值、改状态、存盘 |

模型**碰不到真实数据** —— 它说「你的血量变成 999」没有用，引擎不认。
所以数值不会崩，剧情不会自相矛盾。

## 为什么不做成在线服务

这是一个**软件型**项目：你自己 clone、自己跑、用自己的 API key。

| | 服务型（大家上你的站） | **软件型（本项目）** |
| --- | --- | --- |
| 谁付 API 钱 | 站主，可能被刷爆 | **你自己** |
| 部署 | 要服务器、要运维 | **本地一条命令** |
| 隐私 | 对话经过别人的服务器 | **全在你电脑上** |

## 怎么跑起来

前置条件：**Node.js 18 或更高版本**（[下载](https://nodejs.org/)）。

### 方式一：一键启动（Windows，推荐）

1. clone 仓库（或下载 ZIP 解压）
2. 双击 `public/start.bat`

脚本会自动检测 Node.js、启动服务器、打开浏览器。
**停止服务**：关掉那个窗口，或按 `Ctrl + C`。

### 方式二：手动命令（任何系统）

```bash
# 1. 克隆
git clone https://github.com/me-aqua/TavernGame.git
cd TavernGame

# 2. 启动（零依赖，不需要 npm install）
npm start

# 3. 浏览器打开
#    测试页    http://localhost:3000/
#    游戏界面  http://localhost:3000/play.html
```

## 项目结构

```
TavernGame/
├── index.html           介绍页（GitHub Pages 入口）
├── package.json         启动脚本
├── config.example.json  配置模板
├── assets/              静态素材
├── public/              本地服务器的静态根目录
│   ├── index.html       测试页
│   └── play.html        游戏界面
├── server/
│   └── index.js         零依赖 HTTP 服务器
└── data/                游戏存档（不进仓库）
```

## 设计原则

- **零依赖** —— 服务器只用 Node 内置模块
- **单进程** —— 一个命令启动，一个文件存数据
- **模型与事实分离** —— 见上文
- **不追求和酒馆兼容** —— 玩法不同，没必要迁就旧格式
