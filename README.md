## 这个仓库目前有什么

只有一个稳定的**版本管理基础**：

```
TavernGame/
├── .gitignore      告诉 Git 哪些文件不要纳入版本管理
├── .gitattributes  统一换行符等文件处理细节
└── README.md       本文件
```

## 日常怎么用

```bash
git status                      # 先看有什么改动
git add -A                      # 暂存全部改动
git commit -m "说明改了什么"      # 存档
git push                        # 上传到 GitHub
```

提交信息建议加前缀，方便日后回看：

| 前缀 | 用途 |
| --- | --- |
| `feat:` | 新增功能 |
| `fix:` | 修复问题 |
| `docs:` | 只改文档 |
| `chore:` | 杂项配置 |
