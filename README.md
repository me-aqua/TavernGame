# TavernGame · 酒馆守卫

一个使用**原生 JavaScript + Canvas** 编写的俯视角射击小游戏。

这个项目的另一个目的，是作为**学习 GitHub 版本管理的起点** ——
所以代码里写了大量中文注释，README 里也记录了完整的开发流程。

---

## 🎮 怎么玩

| 操作 | 按键 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或 方向键 |
| 瞄准 | 鼠标 |
| 射击 | 鼠标左键 或 `空格` |
| 暂停 | `P` |
| 开始 / 重开 | `Enter` 或点击按钮 |

**目标**：活得更久。敌人会从画面四周出现并朝你冲过来，
每活 16 秒难度上升一个阶段，蝙蝠（更快、更脆）的比例会越来越高。

## 🚀 怎么运行

### 方式一：直接双击打开（最快）

双击 `index.html` 即可。这是最省事的方式，适合只想看看效果。

### 方式二：本地开发服务器（推荐）

浏览器对 `file://` 协议下的 JavaScript 模块有安全限制，
用 HTTP 服务器打开能避免各种奇怪问题，也是正规开发方式。

打开终端，在本项目目录执行任意一条：

```bash
# 如果你装了 Node.js（本项目开发机已装）
npm run dev

# 或者用 Python
python -m http.server 5173
```

然后在浏览器访问 <http://localhost:5173>。

## 📁 项目结构

```
TavernGame/
├── index.html          页面骨架：画布 + 信息面板 + 开始遮罩
├── package.json        项目描述与命令定义
├── .gitignore          告诉 Git 哪些文件不要纳入版本管理
├── .gitattributes      统一换行符等文件细节
├── styles/
│   └── main.css        全部样式与配色（改顶部变量即可换主题）
└── src/
    ├── main.js         程序入口：启动主循环
    ├── game.js         游戏核心：状态机、碰撞、渲染
    ├── player.js       玩家角色：移动、射击、受伤
    ├── enemy.js        敌人：数据驱动的配置表
    └── utils.js        通用工具函数
```

**为什么这样分文件？**
每个文件只负责一件事。想改玩家手感就打开 `player.js`，
想加新怪物就改 `enemy.js` 里的配置表，不用在读不懂的大文件里翻找。

## 🧠 代码里值得一看的设计

| 设计 | 位置 | 说明 |
| --- | --- | --- |
| **dt 时间步长** | `main.js` | 用「速度 × 每帧耗时」移动，60Hz 和 144Hz 屏幕速度一致 |
| **数据驱动** | `enemy.js` | 加新敌人只需往配置表加一行，无需改逻辑 |
| **状态机** | `game.js` | `ready / running / paused / over` 四种状态，逻辑清晰 |
| **高分屏适配** | `game.js` | 按 `devicePixelRatio` 放大画布，4K 屏不糊 |
| **碰撞优化** | `utils.js` | 用距离平方比较，省掉开方运算 |

## 📌 版本管理备忘（给自己看的）

本项目使用 Git 做版本管理，远程仓库托管在 GitHub。

```bash
# 查看当前状态（最常用，先看这个再决定下一步）
git status

# 查看改动内容
git diff

# 提交一次改动（三步曲）
git add -A                        # 1. 暂存改动
git commit -m "说明这次改了什么"    # 2. 存档
git push                          # 3. 上传到 GitHub

# 查看历史
git log --oneline --graph
```

### 提交信息怎么写

推荐使用约定式提交（Conventional Commits）前缀：

| 前缀 | 用途 |
| --- | --- |
| `feat:` | 新增功能 |
| `fix:` | 修复问题 |
| `docs:` | 只改文档 |
| `style:` | 只改格式，不影响逻辑 |
| `refactor:` | 重构，行为不变 |
| `chore:` | 杂项（配置、依赖等） |

示例：`feat: 增加冲刺技能` / `fix: 修复暂停时仍能射击的问题`
